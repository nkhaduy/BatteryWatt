# BatteryWatt Brand Notes

BatteryWatt should feel like a quiet, native instrument: precise, calm, technical, and useful every day.

## Voice

Use short, concrete sentences. Explain the measurement boundary plainly. Prefer "battery-side power" over vague claims about charger wattage. Avoid hype, growth language, fake metrics, and claims that cannot be measured.

## Visual language

- Graphite `#132029` for the utility surface.
- Warm amber `#F5C24D` for the bolt accent.
- Soft white `#EDF2F4` for the battery silhouette.
- Native macOS semantic colors for interactive UI.
- SF Pro/system typography and monospaced digits for changing values.
- Flat geometry, clear edges, and generous whitespace.

The icon is a simple battery outline with a bolt. It should remain recognizable at 16 px and never depend on a gradient, glow, or detailed illustration.
