# Changelog

All notable changes to BatteryWatt are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use semantic versioning.

## [1.0.0] - 2026-09-03

### Added

- Real-time battery charging and discharging power.
- Native macOS menu bar integration with charging-only default visibility.
- Charging only, Always, On battery only, and Adapter connected modes.
- Native dynamic appearance and template SF Symbol icons.
- Launch at Login.
- Direct AppleSmartBattery telemetry through IOKit.
- Optional local history, session statistics, approximate energy estimates, and CSV export.
- Sanitized diagnostics for support requests.
- Command-line builds, DMG/ZIP packaging, checksums, CI, and tagged release automation.

### Notes

- The initial public artifact is ad-hoc signed and not notarized.
- Intel hardware support is not verified on physical Intel hardware yet.
