# Contributor Covenant Code of Conduct

## Our pledge

We are committed to making participation in BatteryWatt welcoming, respectful, and harassment-free for everyone.

## Our standards

Positive behavior includes empathy, constructive feedback, patience, and respect for different viewpoints. Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, and publishing private information.

## Enforcement

Project maintainers may remove comments, close issues, or reject contributions that violate this code. Report concerns privately through GitHub's repository reporting tools rather than escalating them in public threads.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
