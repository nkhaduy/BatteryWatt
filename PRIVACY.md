# Privacy

BatteryWatt does not collect personal data. It has no analytics, tracking, accounts, ads, cloud sync, or telemetry upload, and it makes no network requests for normal operation.

Battery readings are processed on-device. Optional power history is stored locally in the user's Application Support directory, is disabled by default, is bounded by the selected retention period, and can be exported only by an explicit user action.

Diagnostics intentionally omit usernames, home paths, serial numbers, and device identifiers.
